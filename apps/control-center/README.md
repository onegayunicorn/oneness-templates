# ONENESS Control Center

Responsive Mineral Signal frontend shell for pathway discovery, capability composition, plugin provenance, application materialization, project inspection, audit, and deployment lifecycle visibility.

The production-ready managed frontend lives in the ONENESS Control Center web project. This directory mirrors the primary source files into the ONENESS monorepo so the UI architecture is versioned alongside the platform packages.

The frontend intentionally uses static operational data until the platform control API is implemented. Runtime providers, service adapters, and deployment actions remain explicitly gated in the UI.
